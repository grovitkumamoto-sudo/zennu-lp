## 次のチャットでの進め方

1. このリポジトリを作業場所に選び、`AGENTS.md` とこのノートを読む。
2. `git status` と最新の `origin/main` を確認し、今回の依頼に関係するページを開く。
3. 依頼された範囲だけ修正し、ローカルプレビューで表示・操作を確認する。
4. 本番反映は依頼があったときだけ行い、公開URLで結果を確認する。

このノートには未完了作業を常に残す必要はない。新しい変更で判断に影響する決定・未解決事項・公開状況が生じたときだけ、日付とともに更新する。
