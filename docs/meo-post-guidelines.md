# MEO投稿 下書き生成ガイドライン

Googleビジネスプロフィールの「投稿」下書きを自動生成する際、このガイドラインに沿って作成する。
実際の投稿はGoogleビジネスプロフィールの投稿API(Local Posts)が利用可能か確認の上、
①Chatworkで下書きを送る→②人が確認→③承認後に投稿、のフローを想定。

## 仕様

- 文字数: 150〜300文字。検索結果のプレビューは先頭約100文字で切れるため、**最初の100文字だけで意味が完結する**ように書く
- 画像: 必須。トレーナー・館内・トレーニング風景・食事指導の様子など。横長なら720×540px以上(4:3)、正方形なら1200×1200px推奨
- CTAボタン: 「予約する」「詳細を見る」などを内容に応じて提案する
- 投稿頻度目安: 週1回程度(通常投稿は約7日で表示上目立たなくなるため)

## ブランドトーン

現行LP(lp.zennuwellnessdesign.jp)のコンセプトに準拠する。

- キャッチコピー: 「続けることから、変わっていく」
- 訴求軸: 無理なく続けられる、意志の強さに頼らない仕組み、初心者・運動未経験者がほとんど
- 差別化: セルフ×パーソナルのハイブリッド、元大手パーソナルジム店長のトレーナー、糖質制限なしの食事指導(臨床栄養医学指導士)
- 立地: 熊本市中央区上通アーケード内、通町筋駅徒歩1〜4分

## ターゲットキーワード(ローテーション方式)

**1投稿につき軸となるキーワードは1〜2個に絞る**。全部を毎回詰め込むと不自然で逆効果。
週替わりで以下の軸をローテーションさせ、月を通してすべてのキーワードをカバーする。

| 軸 | 主なキーワード | 訴求内容の例 |
|---|---|---|
| ダイエット軸 | ダイエット、熊本 | 食事指導、体組成の変化、リバウンドしない体づくり |
| 筋トレ・パーソナル軸 | パーソナルジム、筋トレ、熊本 | トレーナー紹介、セルフ×パーソナルの仕組み |
| ピラティス・姿勢改善軸 | ピラティス、姿勢改善 | 猫背・反り腰改善、産後の体型戻し |
| アクセス軸 | 上通り、熊本市中央区 | 上通アーケード徒歩0分、通いやすさ |
| キャンペーン軸 | (固定訴求と組み合わせ) | 無料体験、先着◯名、入会金0円 |

## テンプレート構成

1. **フック(最初の1文、〜40文字)**: 軸キーワード+悩みへの問いかけ or ベネフィット
2. **本文(続き、100〜200文字)**: 具体的な内容・実績・安心材料
3. **CTA(最後の1文)**: 「まずは無料体験へ」等、行動を促す一言

## サンプル下書き(軸ごと)

**ダイエット軸**
> 熊本でリバウンドしない体づくりを。ZenNuは糖質制限なし、臨床栄養医学指導士による「食べながら痩せる」食事指導と、セルフ×パーソナルの併用で"続けられる"を仕組み化しています。実績300名以上、平均−6kg/3ヶ月。まずは無料体験へ。
（画像案: Before/After写真 または 食事指導風景）

**筋トレ・パーソナル軸**
> 熊本のパーソナルジムZenNuでは、元大手パーソナルジム店長のトレーナーが、あなたのペースに合わせて指導します。筋トレが初めての方がほとんど。無理なく続けられるメニューで理想の体へ。まずは無料体験からどうぞ。
（画像案: トレーナーが指導している様子）

**ピラティス・姿勢改善軸**
> 猫背や産後の体型戻しにお悩みの方へ。ZenNuではピラティス要素も取り入れた指導で、姿勢からカラダを整えます。運動未経験の方も安心してご相談ください。まずは無料体験へ。
（画像案: ストレッチ・ピラティス指導風景）

**アクセス軸**
> 上通アーケード内、通町筋駅から徒歩1分。熊本市中央区でパーソナルジムをお探しなら、仕事帰り・お買い物のついでにも通いやすいZenNuへ。セルフ利用は7時〜22時で営業中です。
（画像案: 店舗外観・エントランス）

## 生成時の注意

- 毎回まったく同じ文章にならないよう、実績数値・トレーナー名・具体的な悩みの表現に変化をつける
- キャンペーン内容(先着人数・特典)は最新のLPの内容と必ず一致させる
- 誇張・断定的な効果保証の表現は避ける(景品表示法・医療広告的な誤解を避けるため、「個人差があります」等の一般的な配慮を意識)
